## Usage
To use this application, update the .env files with the appropriate values.

The client .env file requires the IP Address of the server

The server .env file requires the IP Address of the server, the email address used to send emails to the users, and the password for that email

Once these values have been established, save the server folder to the location where the server files are to be saved, and distribute the client folder to any users who will use it.

The server can be run with the command:

'''python
python main.py
'''

Once the server is running, the client can be run with the same command:

'''python
python main.py
'''
